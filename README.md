# 🚌 نظام متابعة وحساب سائقي ورحلات الحافلات
# Bus Driver & Fleet Tracker (Web & Flutter Cross-Platform)

نظام متكامل واحترافي لإدارة ومتابعة رحلات سائقي الحافلات، أسطول الحافلات الكبيرة (سعة 50 راكب)، تسجيل الرحلات اليومية والوقود، والتقارير الشهرية بنمط Excel. متوفر بنسختين: **تطبيق ويب تفاعلي حديث** و**تطبيق هاتف ذكي عبر Flutter**.

---

## 🌟 الميزات الرئيسية (Key Features)

1. **لوحة التحكم والإحصائيات (Analytics Dashboard):**
   - مؤشرات أداء فورية: إجمالي الرحلات، السائقين النشطين، إجمالي الإيرادات، تكاليف الوقود، وصافي الأرباح.
   - **قسم مخصص لحافلات النقل الكبيرة (50 راكب):** تتبع عدد الرحلات، مجموع الركاب، ومعدل استغلال المقاعد (Capacity Utilization %) مع مقياس تفاعلي ملون.
2. **سجل الرحلات اليومية والعمليات (Daily Trip Logs):**
   - تسجيل الرحلات مع السائق، رقم الحافلة، المسار، عدد الركاب، تكلفة الوقود، والإيراد.
   - شريط حسابات ديناميكي أسفل الجدول يجمع الركاب، الإشغال، والوقود والإيرادات فورياً.
3. **التقارير الشهرية وجداول إكسل (Monthly Summary & Reports):**
   - تجميع محاسبي شامل لكل سائق بنمط Excel.
   - تصدير مباشر إلى ملف **Excel (CSV)** مع ترميز `UTF-8 BOM` لدعم اللغة العربية بدون تشويش.
4. **حضور وأجور السائقين (Attendance & Wages):**
   - جدول حضور تفاعلي يتيح التبديل السريع (عمل 🟢، راحة 🔵، غياب 🔴، إجازة 🟠).
   - **نظام المناوبة (يوم عمل ويوم راحة - 1x1):** تطبيق التناوب التلقائي على الشهر بضغطة زر واحدة.
   - حساب الأجر الأساسي، الساعات الإضافية، البدلات والخصومات.
5. **دعم ثنائي اللغة (Bilingual Support):**
   - تبديل سلس بنقرة واحدة بين **العربية (RTL)** و **الإنجليزية (LTR)**.
6. **بناء تلقائي عبر GitHub Actions (CI/CD):**
   - بناء ملف Android APK تلقائياً عند أي تحديث في المستودع.

## 📁 هيكلية المشروع (Project Structure)

```text
Bus_Driver_Tracker/
├── .github/
│   └── workflows/
│       └── flutter_build.yml      # البناء التلقائي للـ APK على GitHub Actions
├── .gitignore                     # استثناء الملفات المؤقتة وملفات البناء
├── README.md                      # دليل الاستخدام والتشغيل

├── style.css                      # التنسيقات الإضافية والطباعة A4

├── server.ps1 / tunnel.ps1        # خادم المشاركة عبر الواي فاي والرابط العام
└── bus_driver_tracker_app/        # تطبيق Flutter للهواتف والحواسيب
    ├── pubspec.yaml               # مكتبات Flutter
    ├── lib/
    │   ├── main.dart              # نقطة انطلاق التطبيق
    │   ├── models/                # نماذج البيانات (Driver, Trip, Attendance)
    │   ├── services/              # إدارة الحالة والتخزين المحلي
    │   ├── screens/               # واجهات التطبيق (Dashboard, Trips, Reports, etc.)
    │   └── theme/                 # التنسيقات والألوان
    └── android/                   # إعدادات منصة أندرويد
```

## 🚀 أوامر الرفع والتحديث على GitHub (Git Setup)

لقد تم ربط هذا المستودع مع الرابط التالي:
`https://github.com/abdessamie70-dotcom/Bus-Driver-Tracker.git`

لتحديث الكود ورفعه على GitHub:

```bash

git add .

# 2. إنشاء Commit
git commit -m "feat: complete Bus Driver Tracker web and Flutter mobile app"

# 3. تحديد الفرع الرئيسي
git branch -M main

# 4. الرفع إلى GitHub
git push -u origin main
```

> **ملاحظة:** عند تنفيذ `git push` للمرة الأولى، سيطلب منك المتصفح أو موجه الأوامر تسجيل الدخول بحساب GitHub الخاص بك عبر (Personal Access Token أو المتصفح).
